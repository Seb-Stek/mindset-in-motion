# Mindset in Motion: website

The website for **Mindset in Motion**, a youth-led nonprofit that runs free soccer games, lessons and races with underserved communities.

## Run it
Open `index.html` in a browser. It doesn't need a build step.

## Edit content
Everything you'll want to change is in the `CONFIG` object at the top of `script.js`:
- `team`: names, roles, bios and headshots
- `events`: event titles, dates, partners and highlights
- `photos`: gallery images (files go in `/photos`)
- `sports`: options in the "vote for the next sport" section
- `contactEmail`: where the "Get involved" form sends messages
